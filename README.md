# Shoplist

A simple Android shopping list app built with Kotlin and Jetpack Compose. Organize products by category, add notes, mark items as purchased, and clear completed purchases. Previously used product names and categories are available for quick reuse, and your list is saved locally.

**Tech stack:** Kotlin, Jetpack Compose, Material 3, MVVM, Room, Hilt, Coroutines and StateFlow.

**Requires:** Android 7.0 (API 24) or newer.
